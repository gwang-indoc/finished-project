### 2. Fix `share-toggle.tsx` lint error with `useSyncExternalStore`
**Commit:** `5cacf15`

**Feature:**
- Replaced the `useState('') + useEffect(setOrigin)` pair in `components/share-toggle.tsx` with `useSyncExternalStore(() => () => {}, () => window.location.origin, () => '')`. Drops the `useEffect` import; observable rendering behavior is identical (SSR/first paint shows no public URL block, absolute URL appears after hydration). Resolves the previously-flagged `react-hooks/set-state-in-effect` violation without suppressing the rule.
- Added a new `note-sharing` capability spec (`openspec/changes/fix-share-toggle-lint-error/specs/note-sharing/spec.md`) with one ADDED requirement: "Public note URL renders without SSR/CSR hydration mismatch", covering the SSR-safe rendering contract this refactor preserves. Two scenarios: URL hidden during SSR/first paint, absolute URL visible post-hydration when sharing is on.
- Brainstorming spec captured at `docs/superpowers/specs/2026-04-29-share-toggle-lint-fix-design.md`; full alternatives analysis (lazy-init, eslint-disable, relative-URL) lives there and in `design.md` Decision 1.
